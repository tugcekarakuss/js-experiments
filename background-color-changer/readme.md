# Background Color Changer

A simple JavaScript project that changes the background color of the page each time the user clicks the button. This project was created as part of my JavaScript learning process, focusing on DOM manipulation and event handling.

## 🖼️ Preview

![Background Color Changer Preview](project-preview.gif)

## 🎯 Purpose of the Project
The goal of this mini project is to practice:
- Selecting and manipulating DOM elements
- Handling user interactions with event listeners
- Updating content dynamically
- Using arrays and basic logic to cycle through values

## 🧪 How It Works
- A fixed array of colors is defined in the JavaScript file.
- Each button click triggers the `changeColor()` function.
- The background color of the page changes to the next color in the array.
- The current color value is also displayed on the screen.
- When the end of the array is reached, it loops back to the beginning.

## 📘 What I Learned
- How to select DOM elements using `document.querySelector()`
- How to update styles dynamically with JavaScript
- How to change inner text of an element using `.innerText`
- How to handle click events with `addEventListener`
- How to use arrays and manage index values to loop through data

## ▶️ How to Run
1. Download or clone the project.
2. Open `index.html` in your browser.
3. Click the button to change the background color.
