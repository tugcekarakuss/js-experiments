# Flashcard App

This is a simple flashcard application built with vanilla JavaScript.
Users can create, view, and delete flashcards. All flashcards are stored
in the browser using localStorage, so the data persists after page reloads.

## Preview  
<img src="project-preview.gif" alt="Flashcard App Preview">

## Features

- Create new flashcards (question & answer)
- Display saved flashcards
- Show/hide answers by click
- Delete all flashcards at once
- Persistent data using localStorage

## Technologies Used

- HTML
- CSS
- JavaScript (Vanilla)

## Project Structure

index.html  
style.css  
script.js  

## How It Works

- The user clicks **New Card** to open the flashcard form.
- The user enters a question and an answer.
- Clicking **Save** creates a new flashcard and stores it in localStorage.
- Clicking a card toggles the visibility of the answer.
- Clicking **Delete Cards** removes all flashcards from the page and storage.

## How to Run

1. Clone or download the repository.
2. Open `index.html` in a browser.
3. Create and manage flashcards directly in the browser.

## Notes

This project was created for learning purposes to practice DOM manipulation,
event handling, and working with localStorage using JavaScript.
