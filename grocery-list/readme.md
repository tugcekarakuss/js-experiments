# Grocery List App

This is a simple grocery list application built with vanilla JavaScript.
Users can add items to a list, mark them as completed, delete individual items,
or clear the entire list. All interactions happen without reloading the page.

## Preview  
<img src="img/project-preview.gif"  alt="Grocery List Project Preview">

## Features

- Add new grocery items
- Add items by clicking the button or pressing Enter
- Mark items as completed
- Delete individual items
- Clear all items at once
- Prevent actions when the list is empty

## Technologies Used

- HTML
- CSS
- JavaScript (Vanilla)

## Project Structure

index.html  
style.css  
script.js  

## How It Works

- The user types an item into the input field.
- Clicking the add button or pressing Enter adds the item to the list.
- Each item has a delete button to remove it from the list.
- Clicking on the item text marks it as completed.
- The clear button removes all items from the list.

## How to Run

1. Clone or download the repository.
2. Open index.html in a browser.
3. Start adding grocery items.
