# Expense Tracker App

This is a simple Expense Tracker application built with vanilla JavaScript.
Users can add expenses, delete them, and see the total amount update instantly
without reloading the page.

## Preview
<img src="./project-preview.gif" alt="Expense Tracker App Preview">

## Features

- Add new expenses with name and amount
- Validate empty or invalid inputs
- Display expenses in a list
- Delete individual expenses
- Automatically calculate and update total amount
- Dynamic UI updates using DOM manipulation

## Technologies Used

- HTML
- CSS
- JavaScript (Vanilla)

## Project Structure

index.html  
style.css  
script.js  

## How It Works

- The user enters an expense name and amount.
- Clicking the **Add** button adds the expense to the list.
- Each expense item displays:
  - Expense name
  - Amount
  - Delete button
- The total amount updates when:
  - A new expense is added
  - An existing expense is deleted
- All updates happen dynamically without page refresh.

## How to Run

1. Clone or download the repository.
2. Open `index.html` in a browser.
3. Start adding and managing your expenses.
