# Pass The Message 

A simple JavaScript project that allows users to type a message and display it instantly on the page. Users can submit the message by clicking the Send button or pressing the Enter key. This mini project focuses on DOM manipulation, event handling, input validation, and dynamic content updates.

## 🎯 Purpose of the Project  

The main goal of this project is to practice:

- Selecting and updating DOM elements  
- Handling user interactions through click and keyboard events  
- Displaying dynamic text content  
- Writing clean and reusable functions  


## 🧪 How It Works  

- The user types a message into the input field.
- When the user clicks the `Send` button or presses `Enter`, the getMessage() function is executed. 
- This function:
  - Checks if the input is empty
  - Displays a warning message if empty: "Hey, you forgot to type something 😑"
  - Otherwise, displays the typed message in the output box  
  - Clears the input field after displaying the message


- The message updates instantly without reloading the page.
