# Notes App

This is a simple Notes application built with vanilla JavaScript.
Users can add notes, delete them, and interact with the app dynamically
without reloading the page.

## Preview
<img src="./project-preview.gif" alt="Notes App Preview">

## Features

- Add new notes using input field
- Add notes by clicking the button or pressing Enter
- Validate empty input
- Display notes in a list
- Delete individual notes
- Dynamic UI updates using DOM manipulation

## Technologies Used

- HTML
- CSS
- JavaScript (Vanilla)

## Project Structure

index.html  
style.css  
script.js  

## How It Works

- The user types a note into the input field.
- Clicking the **Add** button or pressing **Enter** adds the note to the list.
- Each note item contains:
  - Note text
  - Delete button
- Clicking the delete button removes the note from the list.
- All updates happen dynamically without page refresh.

## How to Run

1. Clone or download the repository.
2. Open `index.html` in a browser.
3. Start adding and deleting notes.
