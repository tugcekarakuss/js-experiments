# Tip Calculator App

This is a simple tip calculator application built with vanilla JavaScript.
Users can calculate the tip per person based on the total bill amount,
number of guests, and service quality. The calculation happens instantly
without reloading the page.

## Preview  
<img src="img/project-preview.gif" alt="Tip Calculator Project Preview">

## Features

- Enter total bill amount
- Enter number of guests
- Select service quality
- Calculate tip per person
- Clear all inputs with one click

## Technologies Used

- HTML
- CSS
- JavaScript (Vanilla)

## Project Structure

index.html  
style.css  
script.js  

## How It Works

- The user enters the total bill amount.
- The user enters the number of guests.
- The user selects a service quality option.
- Clicking the **Calculate** button displays the tip per person.
- Clicking the **Clear** button resets all inputs and hides the result.

## How to Run

1. Clone or download the repository.
2. Open index.html in a browser.
3. Enter the bill details and calculate the tip.

## Notes

This project was created for learning purposes to practice DOM manipulation,
event handling, and basic form validation using JavaScript.
