# Todo Filter App

This is a simple Todo application built with vanilla JavaScript.
Users can add todos, mark them as completed, and filter the list
by all, active, or completed items without reloading the page.

## Preview
<img src="./project-preview.gif" alt="Todo Filter App Preview">

## Features

- Add new todos
- Add todos using the Enter key
- Mark todos as completed
- Filter todos by:
  - All
  - Active
  - Completed
- Dynamic UI updates using DOM manipulation

## Technologies Used

- HTML
- CSS
- JavaScript (Vanilla)

## Project Structure

index.html  
style.css  
script.js  

## How It Works

- The user types a todo into the input field.
- Clicking the **Add** button or pressing **Enter** adds the todo to the list.
- Each todo has a **Complete** button.
- Clicking **Complete** toggles the completed state of the todo.
- Filter buttons control which todos are visible:
  - **All** shows all todos
  - **Active** shows only uncompleted todos
  - **Completed** shows only completed todos

## How to Run

1. Clone or download the repository.
2. Open `index.html` in a browser.
3. Start adding and managing your todos.
